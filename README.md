# MadLibs

A simple command-line Mad Libs game written in Java.

The program asks you for a series of words (adjectives, verbs, nouns, etc.), then plugs them into a story and prints the result.

## Requirements

- Java JDK 11 or newer
- IntelliJ IDEA (optional, but recommended)

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/<your-username>/MadLibs.git
   ```
2. Open the project in IntelliJ IDEA.
3. Run `Main.java`.
4. Type a word when prompted and press Enter. Repeat until the story is printed.
